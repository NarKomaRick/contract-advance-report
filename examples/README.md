# Проверочный пример отчёта

В папке `2026-11-10/` сохранён результат работы программы на исходных данных
из `data/` на дату 10.11.2026 включительно.

| Файл | Назначение |
|---|---|
| [2026-11-10/works.csv](2026-11-10/works.csv) | Детализация по работам: статус на дату, цена, обязательство, прямые платежи, доля общих платежей, общая оплата, остаток и переплата. |
| [2026-11-10/contracts.csv](2026-11-10/contracts.csv) | Сводка по договорам: цены работ, перечисления, возвраты, чистая оплата, свободный аванс, остатки и примечания. |
| [README.md](README.md) | Это пояснение к примеру и команда его воспроизведения. |

Чистая оплата составляет 315000.00 руб. по D-1 и 75000.00 руб. по D-2.
Доли оплаты отдельных работ зависят от допущений, описанных в [DECISIONS.md](../DECISIONS.md).
Значение «Осталось оплатить» включает будущие работы и не означает просрочку.
Все колонки подробно объяснены в [RUN.md](../RUN.md).

Для повторного расчёта из корня проекта:

```powershell
python report.py --data-dir data --date 2026-11-10 --output reports/2026-11-10
```

Укажите новую папку `--output`, если такая уже существует. Файлы примера являются
сохранённым результатом, не обновляются автоматически и не используются как входная выгрузка.
