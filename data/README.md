# Исходные данные

Эта папка содержит входную выгрузку для расчёта. Исходные CSV и `FORMAT.md`
сохранены без изменений. Программа читает их, но не записывает в них результаты.

| Файл | Назначение |
|---|---|
| [contracts.csv](contracts.csv) | Договоры с подрядчиками: сумма и дата подписания. `contract_id` связывает договор с работами и платежами. |
| [works.csv](works.csv) | Работы по договорам: цена, название, текущий статус, даты приёмки и отмены. `work_id` используется для прямой привязки платежа. |
| [payments.csv](payments.csv) | Платежи, даты перечислений и возвратов. Пустой `work_id` означает общую оплату договора, которую программа распределяет расчётным способом. |
| [FORMAT.md](FORMAT.md) | Полное исходное описание колонок и значений статусов. |
| [README.md](README.md) | Это пояснение к составу папки и связям между входными файлами. |

Текущий статус отражает момент выгрузки, поэтому состояние на выбранную дату
восстанавливается по датам событий. Назначение платежа является текстовым описанием,
а не инструкцией для алгоритма. Правила учёта описаны в [DECISIONS.md](../DECISIONS.md).

Результат записывается отдельно, обычно в `reports/ДАТА/`.
Проверочный пример находится в [examples/2026-11-10/](../examples/2026-11-10/).
